# Simple Interest Calculator

## Project Description
This project is a simple interest calculator that calculates the interest earned on a principal amount based on the annual interest rate and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input Fields
- Principal: The initial amount of money.
- Rate: The annual rate of interest.
- Time: The time period in years.

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Technology Used
- Bash Scripting

## How to Use
Run the simple-interest.sh script and enter the principal amount, rate of interest, and time period when prompted.
